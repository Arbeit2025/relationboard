# キャラ相関図ボード（relationboard）

自作キャラクター同士の関係を線でつないで、相関図として眺めるための小さなボードです。着想元は GitHub フォロワーの mofu-mitsu さんのオリキャラ相関図（orikyara-relationship-chart）です。

## 機能

- **キャラクター登録**：名前と任意のメモを登録できます。一覧から削除もできます（削除すると、そのキャラクターに結ばれた関係も一緒に消えます）。
- **関係の登録**：キャラA・キャラB・関係ラベル（例：友人／ライバル／家族。プリセット候補あり、自由入力も可）を登録・削除できます。同じキャラクター同士の関係は登録できません。
- **相関図**：サーバー側で SVG を生成します。キャラクターを円周上に配置し、関係のあるキャラクター同士を線で結び、線の近くに関係ラベルを表示します。外部 JS ライブラリは使いません。
- ユーザー入力（名前・メモ・ラベル）は HTML エスケープして表示します（SVG 内のテキストも同様です）。

データは SQLite に保存します。DB のパスは環境変数 `RELATIONBOARD_DB` で変更できます。

## ローカル実行

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000
```

## テスト

```bash
python -m unittest discover -s tests
```

## Render へのデプロイ

`render.yaml` 同梱。無料プラン（free）の Web Service としてデプロイできます（healthCheckPath: `/healthz`）。

## 制限事項（正直なところ）

- ログイン機能はありません。
- Render 無料プランでは SQLite のデータが再デプロイ等で消える場合があります。大事な相関図は手元にも控えを残してください。
- 相関図のレイアウトは円形配置のみです。キャラクターが多いと名前やラベルが重なって見づらくなることがあります。
